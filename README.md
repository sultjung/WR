# 이라크 주간상황보고서 뉴스자료

㈜한화 건설부문 비스마야 신도시 사업을 위한 **아랍어 현지뉴스 자동수집·한국어 전문번역·기사 선별·GPT 전달용 Word 다운로드 시스템**입니다.

최종 주간상황보고서는 이 저장소에서 자동 생성하지 않습니다. 사이트에서 담당자가 필요한 기사를 선택해 Word 자료집을 내려받고, 별도로 구성한 주간상황보고서 전용 ChatGPT에 업로드해 최종 보고서를 작성하는 구조입니다.

## 운영 원칙

- 공개 GitHub Pages 기반 뉴스 검토 사이트
- 최근 14일 범위의 이라크·비스마야 관련 아랍어 뉴스 수집
- 원문 URL과 아랍어 본문 전문 확보
- 관련성·카테고리·중복사건 그룹·중요도는 자동 처리
- 기사 제목은 원문의 의미를 보존해 한국어로 충실 번역
- 기사 본문은 요약·재작성하지 않고 한국어 전문번역
- 기본 카드에는 전문 앞부분만 표시하고 `전문 펼쳐보기`에서 전체 번역 확인
- 담당자가 최종 보고서 후보 기사를 직접 선택
- 선택 기사만 `WR_SELECTED_ARTICLES_YYYY-MM-DD.docx`로 즉시 다운로드
- 최종 보고서용 OpenAI API 호출과 GitHub Actions 보고서 생성은 사용하지 않음

## 전체 흐름

1. `Collect Arabic News`가 아랍어 뉴스 후보를 검색합니다.
2. 원문 URL을 복구·검증하고 실제 아랍어 본문 전문을 수집합니다.
3. 이라크 범위와 카테고리 적합성을 검사합니다.
4. 동일 사건 보도를 관련뉴스로 묶습니다.
5. 카테고리 기준 중요도를 계산합니다.
6. 대표기사의 아랍어 제목과 본문 전체를 한국어로 번역합니다.
7. 사이트에서 번역 전문을 펼쳐 읽고 필요한 기사를 선택합니다.
8. 보고일을 지정하면 대상기간이 자동으로 `보고일 D-7 ~ D-1`로 계산됩니다.
9. `선택 기사 Word 다운로드`를 누르면 GPT 입력용 DOCX 자료집이 생성됩니다.
10. 해당 DOCX를 주간상황보고서 전용 ChatGPT에 업로드해 최종 보고서를 작성합니다.

## 전문번역 처리

전문번역은 `FULL_TRANSLATION_V1` 파이프라인을 사용합니다.

저장 필드의 핵심은 다음과 같습니다.

- `originalTitleArabic`: 아랍어 원제
- `originalTextArabic`: 아랍어 원문 전문
- `translation.titleKo`: 원제의 한국어 충실 번역
- `translation.fullTextKo`: 기사 본문의 한국어 전문번역
- `translation.sourceContentHash`: 번역 당시 원문 해시
- `translation.pipelineVersion`: 전문번역 파이프라인 버전

원문 해시가 동일한 기사는 기존 전문번역을 그대로 재사용합니다. 원문이 변경되거나 번역 파이프라인이 변경된 경우에만 `PENDING`으로 되돌려 다시 번역하므로, 정기 수집 때 기존 기사를 반복 번역하지 않습니다.

긴 기사는 일정 길이로 나누어 순서대로 번역한 뒤 다시 합칩니다. 번역 지침은 다음을 금지합니다.

- 기사 요약
- 기사 내용 축약
- 보고서식 재작성
- 원문에 없는 전망·평가·영향 추가
- 숫자·날짜·인명·기관명 임의 변경

## 관련기사

동일 사건으로 판단된 보도는 하나의 대표기사 카드 아래 `관련뉴스`로 묶습니다.

- 대표기사: 제목 + 본문 전문번역
- 중복기사: 관련뉴스 제목 번역 및 원문 링크

중복기사까지 모두 전문번역해 API 비용과 화면 길이를 늘리지 않습니다.

## 중요도 평가

중요도는 비스마야 관련성만으로 평가하지 않고 각 카테고리 안에서 상대평가합니다.

- 비스마야
- 정치권 동향
- 경제·건설
- 테러·치안
- 국제사회

비스마야, 국가투자위원회, 한화, 계약·대금·재원·공사재개 등 사업 직접 관련 사안에는 별도의 사업 중요도 하한 규칙이 적용됩니다.

## 선택 기사 Word 파일

사이트에서 내려받는 DOCX는 최종 보고서가 아니라 **ChatGPT가 보고서를 작성하기 위한 원자료 묶음**입니다.

문서 첫 부분에는 다음 메타데이터가 들어갑니다.

- 문서 유형 `WR_SELECTED_ARTICLES`
- 스키마 버전
- 보고일
- 보고기간 시작·종료일
- 선택 기사 수
- 파일 생성일시

각 기사에는 다음 정보를 일정한 순서로 저장합니다.

- 기사 번호와 기사 ID
- 동일사건 그룹 ID
- 카테고리
- 중요도
- 보도일시
- 언론사
- 원문 URL
- 한국어 제목 번역
- 한국어 본문 전문번역
- 아랍어 제목
- 아랍어 원문 전문
- 관련기사 목록

따라서 전용 ChatGPT에는 별도 설명 없이 이 Word 파일만 업로드해도 보고서 작성에 필요한 원문과 번역문, 기간정보를 함께 전달할 수 있습니다.

정기 수집에서 새로 들어왔거나 원문이 변경된 대표기사만 전문번역합니다.

### Generate Full Article Translations

전문번역 대기 기사를 별도로 처리해야 할 때 수동 실행합니다.

## OpenAI API 사용 범위

현재 API를 사용하는 단계는 다음 두 가지입니다.

1. 기사 중요도 보조 평가
2. 아랍어 기사 제목 및 본문 전문번역

**최종 주간상황보고서 작성에는 저장소의 OpenAI API를 사용하지 않습니다.** 최종 작성은 사용자가 별도로 만든 ChatGPT에서 수행합니다.

저장소 Secret:

- `OPENAI_API_KEY`

선택적 Repository Variables:

- `IMPORTANCE_MODEL`
- `TRANSLATION_MODEL`
- `RELATED_TITLE_MODEL`

- `.github/workflows/generate-article-translations.yml`: 전문번역 수동 실행
